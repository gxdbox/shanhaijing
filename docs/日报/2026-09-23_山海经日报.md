#### ① 犰狳（qiú yú）—— 东山经的"装死小妖"

- **原文出处**：《山海经·东山经·东次一经》餘峩之山
  > "又南三百八十里，曰餘峩之山。其上多梓枏，其下多荊芑。雜余之水出焉，東流注于黃水。有獸焉，其狀如菟而鳥喙，鴟目蛇尾，見人則眠，名曰犰狳，其鳴自訆，見則螽蝗為敗。"
- **外貌描述（像素画设计稿）**：**兔身 + 鸟喙 + 鸱枭眼 + 蛇尾**四拼怪——主体兔形（约 12×10px，通体土黄/浅棕，圆胖），**嘴是尖尖鸟喙**（2-3px 喙尖朝下，深色），**双眼大而圆如猫头鹰**（黄瞳 2×2，夜间发亮是记忆点），**尾巴是条细蛇**（尾端 4px 卷曲，蛇头微翘，可与兔身不同色）。像素画重点：让"兔身 + 鸱目"的正脸错位感强烈，配合"见人则眠"做**装死帧**（倒地、闭眼、四脚朝天，受击时无反应——这是它的标志演出）。
- **习性/能力**：**见人则眠**——见到人就装死倒地（史上最早的"装死防御"记录）；**其鸣自訆**（叫声像在喊自己名字）；**见则螽蝗为败**——它一出现，蝗虫就会败退（驱蝗瑞兽）。
- **居住地**：东次一经·餘峩之山（多梓枏良木，山下多荊芑；雜余水东流入黄河）。
- **游戏化建议**：
  - 属性：**土**（田地护稼、驱蝗）｜稀有度：**普通**（东荒野怪池主力，视觉★但机制★★★）｜收服难度：**低**（前期 3-5 级可收）
  - 候选技能：**装死**（防御/受击免伤，机制亮点）、**鸣自訆**（物理单攻）、**驱蝗**（魔法单攻，克制虫类）
  - **核心盼头：装死被动——血量低于 30% 概率免伤一回合，前期坦克位黑马**

#### ② 夫诸（fū zhū）—— 中山经的"大水白鹿"

- **原文出处**：《山海经·中山经·中次三经》敖岸之山
  > "《中次三經》萯山之首，曰敖岸之山，其陽多㻬琈之玉，其陰多赭、黃金。神熏池居之，是常出美玉。北望河林，其狀如莤如舉。有獸焉，其狀如白鹿而四角，名曰夫諸，見則其邑大水。"
- **外貌描述（像素画设计稿）**：**白鹿 + 四角**是全部记忆点——通体**纯白**（白底 3 档灰度表现毛色，亮到发光，夜晚有柔光帧），**四只角**（头顶两对鹿角，前后错开：前角较短 4px、后角较长分叉 6-8px，淡金色），体型优雅修长（约 16×12px，比鹿蜀更纤长）；四蹄踏水（脚底 1-2px 水花粒子）。待机动画做"昂首望河"帧——呼应"北望河林"。配色走"白玉 + 淡金角 + 水蓝光效"，与鹿蜀（白头虎纹赤尾）严格区分。
- **习性/能力**：**见则其邑大水**——它现身，当地就要发大水（水灾兆兽，但本身是美丽瑞相的白鹿）；敖岸之山有**神熏池**居于此，常出美玉。
- **居住地**：中次三经·敖岸之山（山南多㻬琈美玉，山北多赭石黄金；是"帝之密都"青要之山相邻的圣山）。
- **游戏化建议**：

  - 候选技能：**洪水兆**（群体法术）、**白鹿灵**（治疗/增益）、**圣山玉气**（buff，防御提升）
  - **世界观钩子：与青要之山"帝之密都"绑定，是"中荒帝都圈"剧情的开场引子**

#### ③ 马腹（mǎ fù）—— 中山经的"人面虎"食人凶兽

- **原文出处**：《山海经·中山经·中次二经》蔓渠之山

- **外貌描述（像素画设计稿）**：**人面 + 虎身**的恐怖组合——虎形身躯（约 18×12px，强健，通体玄黄/赤褐虎纹），**头部是张人面**（面部朝前，肉色五官，表情阴郁，与蛊雕的"婴儿音诱食"同气质）；虎爪锋利，尾巴粗壮。像素画重点：**"人面"用最简的肉色 + 黑眼 + 抿唇**，配合虎身产生惊悚错位；攻击帧做"张开人嘴露出虎牙"（人嘴变血盆大口的变脸演出，是全游戏最有冲击力的凶兽动画之一）。音效：婴儿啼哭混虎啸。

### 3.【剧情素材】

**典故一：帝之密都・青要之山（夫诸主线引子）**
中次三经紧邻敖岸之山的是**青要之山——"實惟帝之密都"（天帝的秘密行宫）**，南望墠渚是"禹父之所化"（大禹之父鲧被殛后所化之处），神武罗（人面豹纹、穿耳珰、鸣如玉）司掌此山，"宜女子"。
> **主线草稿（中荒・帝都圈入口）**：
> 引路人：此地往前，便是青要之山——天帝的密都。都说大禹治水时，他那被殛的父亲鲧便化在墠渚之地。山上有神武罗，人面豹纹，鸣声如玉；山旁敖岸之山住着白鹿夫诸，它一现身，便要发大水。天帝密都的风水，凡人本不该擅入……可你身上那卷《山海经》，怕是与它有缘。
> 收服夫诸后 → 解锁青要之山·密都线索（主线推进点）。

**典故二：東次一經・蝗灾与装死（犰狳支线）**
> **支线草稿（东荒・餘峩山脚村落）**：
> 老农：客官来得正好！今年蝗虫铺天盖地，田里的庄稼眼看要完了。老辈说，餘峩山上住着个小妖，兔身鸟嘴，一见人就四脚朝天装死——它一现身，蝗虫就全败退了。可它滑溜得很，一见人就躺下，抓也抓不住……
> 玩家：它为什么一见人就装死？
> 老农：嘿嘿，谁知道呢？许是怕生，许是装死骗你走开。你若能收服它，让它替村里驱一场蝗灾，老汉我拿新酿的黍酒谢你！

### 5.【世界观梳理】

- **犰狳：同名异兽的有趣案例**。现代动物"犰狳"（armadillo，穿山甲类）正是借用了这个山海经名字，但**形态完全不同**——现代犰狳是披甲兽，山海经犰狳是"兔身鸟喙鸱目蛇尾"。可作图鉴"考据注"彩蛋：玩家收服后解锁一条注记"后世将披甲之兽亦名犰狳，与此异形"。这也是继肥遗（同名两相）之后第二个"同名话题"收集彩蛋。
- **鹿形兽两极化**。山海经有白鹿/鹿形异兽：**鹿蜀**（杻阳之山，白头虎纹赤尾，佩之宜子孙——**瑞兽**，图鉴已有）vs **夫诸**（敖岸之山，白鹿四角，见则大水——**灾兽**）。一瑞一灾，同属鹿形，可做"鹿形异兽"图鉴页，世界观上暗示"祥瑞与灾异本是一体两面"。
- **"拟声猎食"食人兽家族再添一员**。马腹（人面虎身，音如婴儿）加入蛊雕（雕形有角，音如婴儿）、狍鸮（羊身人面，腋下目，音如婴儿）、诸怀（四角人目彘耳，音如鸣雁）——山海经食人兽普遍"音如婴儿/童声"诱人，这是古人共享的凶兽母题，可做"食人兽"图鉴页的共性文案。
- **中山经＝"帝都圈"世界观金矿**。青要之山（帝之密都）、敖岸之山（神熏池居之）、墠渚（禹父鲧所化）——中山经中次三经一带是**天帝治所 + 大禹传说**的密集区，天然适合做游戏"中荒主线"的核心舞台，异兽世界观可与"帝/禹/四凶"主线挂钩（呼应已有穷奇、四凶合体的终局叙事）。

### 6.【游戏化灵感池】

1. **「装死反击」被动**：犰狳血量低时概率装死免伤一回合，下回合偷袭反击（首击加成）——给坦克位一个独一无二的生存玩法，东荒开门就让玩家记住它。
2. **「同名异兽・考据彩蛋」收集页**：肥遗两相、犰狳古今异形……图鉴新增"考据注"条目，收服对应兽后解锁一条原典/后世演变小知识——给"收集"加第三层"涨知识"的盼头，成本极低、口碑极好。
3. **「灾异兆兽」天气系统**：夫诸（大水）、肥遗（大旱）、獙獙（大旱）、薄鱼（大旱）——"见则XX"灾异兽统一进天气系统雏形：进图时触发对应天气（大水=水系强化/遇敌率变化），并开启治水/求雨支线，把散落的灾异兽串成一个系统。
4. **「帝都圈」主线钩子**：以青要之山"帝之密都"为世界观支点，把中山经的夫诸、武罗、鴢与已有四凶终局主线缝合——"天帝为何封镇山海异兽"成为中后期主线悬念。
