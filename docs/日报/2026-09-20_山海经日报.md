### 1.【今日异兽专题】

#### ① 狍鸮（páo xiāo，别称：饕餮原型/贪兽）

- **原文出处**：《山海经·北山经·北次一经》钩吾之山
  > "又北三百五十里，曰钩吾之山，其上多玉，其下多铜。有兽焉，其状如羊身人面，其目在腋下，虎齿人爪，其音如婴儿，名曰狍鸮，是食人。"
- **外貌描述（像素画设计稿）**：羊身（约 16×14px 四足兽轮廓），人面（面部用 2-3 色肉色像素块，五官朝向玩家），**双目长在腋下**——这是最强记忆点，建议腋下各画一颗上吊眼（白底黑瞳 2×2），平时藏于前肢与躯干之间，攻击时从腋下"翻"出双眼；虎齿外露（嘴部锯齿状 3-4 颗白牙超出下唇），人爪（前肢末端画五指）；通体青灰色调，腹部偏白，符合"钩吾多玉、其下多铜"的矿脉环境色（青玉+铜锈绿）。
- **习性/能力**：食人凶兽；声如婴儿啼哭（诱饵猎食，与蛊雕同类手段）；贪食无厌，吞下活物不止。
- **居住地**：北山经·北次一经·钩吾之山（山上多玉，山下多铜）。
- **游戏化建议**：
  - 攻击属性：**火**（凶焰/贪欲如焚；如后续做克制系统，可克制木、被水克）
  - 稀有度：**精英**（准 Boss，建议做成固定遭遇 + 收服后图鉴彩蛋"饕餮纹"）
  - 收服难度：**高**（需先击败它，再取得"饕餮纹拓片"道具方可结契）
  - 候选技能：**饕餮噬**（魔法单攻）、**婴哭**（物理单攻+震慑）、**腋目**（增益，蜷身洞察）

#### ② 孟极（mèng jí）

- **原文出处**：《山海经·北山经·北次一经》石者之山
  > "又北二百八十里，曰石者之山，其上无草木，多瑶碧。泚水出焉，西流注于河。有兽焉，其状如豹，而文题白身，名曰孟极，是善伏，其鸣自呼。"
- **外貌描述（像素画设计稿）**：雪豹般修长豹身（约 18×10px，体态比狍鸮更瘦长），**通体白色**（白底为主色，用 3 档灰度表现毛色），**额头有花纹**（"文题"=额上斑纹：额部 2×2 深色豹纹块，是区别于普通白豹的关键像素特征）；尾巴细长拖地；眼睛窄长（眯眼画法，体现"善伏"的潜伏气质）。行走/待机动画建议加"压低身形"帧（身体高度缩 2px，尾巴贴地）——把"善伏"做成待机动画本身。
- **习性/能力**：极擅潜伏（"善伏"）；叫声像在喊自己的名字（"其鸣自呼"）。
- **居住地**：北山经·北次一经·石者之山（山上无草木，多瑶碧美玉；泚水西流入河）。
- **游戏化建议**：
  - 攻击属性：**风**（迅捷潜伏、影袭）
  - 稀有度：**普通**（可入北荒野怪池；因"善伏"建议做成"先看破才触发战斗"的机制兽，稀有度视觉上★☆）
  - 收服难度：**低-中**（需先找到它——触发"看破潜伏"小交互，再战斗收服）
  - 候选技能：**善伏・突袭**（物理单攻，首击加成）、**白影**（增益，潜伏防御）、**自鸣**（魔法单攻）

#### ③ 天狗（tiān gǒu）

- **原文出处**：《山海经·西山经·西次三经》阴山
  > "又西三百里，曰阴山。浊浴之水出焉，而南流注于蕃泽，其中多文贝。有兽焉，其状如狸而白首，名曰天狗，其音如榴榴，可以御凶。"
- **外貌描述（像素画设计稿）**：狸猫体型的犬兽（约 12×10px，比狍鸮小一号），**白头**是唯一高亮（头部用纯白 2-3 色，身体用深灰/玄色，形成强烈黑白对比，远处一眼可辨）；郭璞注"或作豹"，可做豹纹暗纹点缀；尾巴蓬松上扬；嘴微张做"榴榴"吠叫帧（音效可用短促犬吠合成音）。待机时建议加"守门"站姿（前腿并拢、昂首），贴合"御凶守关"的定位。
- **习性/能力**：叫声如"榴榴"（一说"猫猫"，即短促吠叫/喵叫）；**可以御凶**——能抵御凶祸邪祟，是西次三经少数正面瑞兽。
- **居住地**：西山经·西次三经·阴山（浊浴水发源，南流入蕃泽，泽中多彩色文贝）。
- **游戏化建议**：
  - 攻击属性：**水**（浊浴之水/净邪御凶）
  - 稀有度：**精英**（剧情固定遭遇，建议做成"天山之路的守关兽"）
  - 收服难度：**中**（需通过"御凶试炼"：证明玩家不是凶邪之人）
  - 候选技能：**御凶**（增益，全队防御/辟邪）、**榴榴音**（魔法单攻）、**白首护**（未来机制：免疫异常）

### 2.【技能灵感】

#### ① 御凶（天狗"可以御凶" → 免疫异常/辟邪机制）
- **技能名**：御凶・白首啸
- **效果描述**：天狗昂首长啸，为**全队**附加"御凶"护体——本场战斗免疫/抵消下一次负面效果（中毒、恐惧、迷惑等），或等效为"全队首回合减伤 20%"。
- **数值建议**：`type: 'buff'`，`power: 0`，`mpCost: 12`，`target: 'ally'`（按现有引擎先做成 buffDef+6；未来加 `statusImmune?: true` 字段实现"免疫异常"，可参考图鉴里九尾狐"食者不蛊"、灌灌"佩之不惑"的同类机制做成**异常免疫家族**）。
- **冷却/消耗**：MP 12，若未来有冷却系统则 CD 3 回合。

#### ② 善伏（孟极"是善伏" → 先制伏击机制）
- **技能名**：善伏・影袭
- **效果描述**：孟极压低身形潜伏一瞬，对目标发动突袭；**若目标本回合尚未行动，则本次伤害 +50%**（首击/偷袭判定）。
- **数值建议**：`type: 'atk'`，`power: 1.8`，`mpCost: 4`，`target: 'enemy'`；先制判定 = 己方 spd 高于目标且目标未行动。
- **冷却/消耗**：MP 4，无冷却；可扩展为**野外被动**：队伍中有孟极/狌狌等高敏兽时，被偷袭概率减半（见第 6 节灵感池）。

#### ③ 饕餮噬（狍鸮"是食人" → 吸血/斩杀机制）
- **技能名**：饕餮噬
- **效果描述**：狍鸮张开虎齿之口撕咬敌人，**造成伤害的 30% 转化为自身生命**（吸血）；若目标生命低于 20%，则触发"吞食"——直接斩杀并回复更多。
- **数值建议**：`type: 'magic'`，`power: 2.0`，`mpCost: 10`，`target: 'enemy'`；吸血系数 0.3 需在 `BattleManager` 增加 `lifesteal?: number` 字段（当前引擎无吸血，建议作为下一期战斗系统扩展点）。
- **冷却/消耗**：MP 10，CD 2 回合（若加冷却系统）。

### 3.【剧情素材】

#### 素材一：狍鸮与"饕餮"之名（主线/图鉴彩蛋）
- **典故**：《左传・文公十八年》载缙云氏有不才子，"贪于饮食，冒于货贿……天下之民以比三凶，谓之饕餮"；《神异经・西荒经》进一步描绘饕餮"身多毛，头上戴豕，贪如狼恶，好自积财"，并明言"《春秋》言饕餮者，缙云氏之不才子也"。学界普遍认为**《山海经》钩吾之山的狍鸮（羊身人面、虎齿人爪、食人）是饕餮形象的原型之一**，商周青铜器上的"饕餮纹"（有首无身）即此凶兽的图腾化。
- **NPC 对话草稿**（新 NPC「老铸师」/长老追加节点，风格对齐 DialogueData）：
  ```
  长老: 阿玄,你可知北荒钩吾之山,山上多玉,山下多铜。
  长老: 上古缙云氏有不才子,贪食无厌,天下人叫他"饕餮"。
  长老: 我族古鼎上刻的饕餮纹,羊身人面,虎齿人爪——与《山海经》所记狍鸮,如出一辙。
  阿玄: 所以那狍鸮……就是饕餮留在山间的影子?
  长老: 去吧。若能收它,你便握住了"贪"字的由来。
  ```

#### 素材二：天狗的守护与误解（支线任务）
- **典故**：《山海经》里的天狗是**御凶瑞兽**（"可以御凶"），与后世"天狗食月"的凶星形象截然不同；《史记・天官书》始载"天狗，状如大奔星"，把天狗星当作兵灾凶兆，民间又衍出"天狗食月"的日月食传说——**从御凶到食月，是天狗形象最大的流变**。
- **NPC 对话草稿**（阴山地图 NPC「守村老妪」+「天狗」）：
  ```
  老妪: 别靠近阴山!那白首的怪物,夜里会吃月亮!
  阿玄: ……(翻开《山海经》)阴山有兽,其状如狸而白首,名曰天狗,可以御凶。
  天狗: (榴榴——榴榴——)三百年来,我守此山,御凶辟邪。
  天狗: 山下的村子,是我看着长大的。可如今,他们怕我胜过怕凶兽。
  阿玄: 御凶之兽,竟被当成了食月之凶……
  天狗: (榴榴——)若你懂我,便来。天山之路,我为你开。
  ```

### 5.【世界观梳理】

- **狍鸮 → 饕餮：凶兽如何变成"四凶"**：游戏里已有**穷奇**（《左传》少皞氏不才子，四凶之一），今日补上狍鸮/饕餮（缙云氏不才子），即可凑齐"四凶"阵营的两席。建议世界观设定：**穷奇与狍鸮同源不同形**——穷奇为"凶"之形（虎翼食人），狍鸮为"贪"之形（羊身人面、饕餮纹）。若未来做梼杌（颛顼氏不才子）、浑敦（帝鸿氏不才子——注意！游戏里帝江"浑敦无面目"恰是浑敦原型，可顺势设定帝江即四凶之首浑敦的"未堕世"形态），四凶闭环就齐了，是很好的长线 Boss 线。
- **天狗：从御凶瑞兽到食月凶星**：《山海经》天狗"可以御凶"（正面）；《史记・天官书》起，天狗星沦为兵灾凶兆（"天狗，状如大奔星"）；民间传说再衍为"天狗食月"（日月食解释，混入佛教罗睺罗吞月的影响）；日本"天狗"（红面长鼻山伏形象）又是另一条支线。**游戏中可做"御凶之名被人遗忘"的悲情支线**（见第 3 节素材二）。
- **三兽关系网**：
  - 天狗 ↔ 狍鸮：**天然对立**（御凶 vs 食人；阴山天狗守护的村落，正是北荒狍鸮猎食的目标）——可做"天狗请求玩家去钩吾山除狍鸮"的连锁任务。
  - 孟极：**中立独行**（与二者无恩怨，纯野怪/可收服），与狌狌（善走）、鹿蜀（温驯）同属"速度系灵兽"小家族，未来可做"山海疾走三兽"图鉴成就。
  - 同山脉：天狗（阴山）与毕方（章莪之山，已在图鉴）同属西次三经，中间仅隔 300 里——可设定为"天山守序阵营"的邻居关系（毕方示警、天狗御凶）。

### 6.【游戏化灵感池】（以下为创意池备选，不强行塞入当前版本）

1. **"御凶结界"探索玩法**：把天狗"御凶"做成**探索向 buff**——玩家带着天狗/持御凶符时，野地遇敌率下降 30%，且战斗首回合全队免一次负面效果。实现思路：`MapView`/`GameManager` 增加 `exploreBuff` 状态，遇敌判定时 `encounterRate *= 0.7`；战斗入场时检查 buff 给全队挂免疫标记。成本低、反馈直观，适合做"收服天狗"的收服奖励。

2. **"善伏"潜伏遭遇机制**：孟极在野外**不可见**（地图上不显示 NPC 块，只在地面留 1 帧"白影"像素），玩家踩到附近才弹出"？？？白影一闪而过"——此时选择"屏息观察"则触发正常战斗，选择"贸然前进"则被偷袭（敌方先手一回合）。实现思路：`FixedEncounterDef` 增加可选字段 `hidden?: true` + `ambush?: true`，BattleManager 支持"敌方先制"回合标记。把"善伏"从一句原文变成一种遭遇体验，记忆点极强。

3. **"饕餮纹"收集与铸造**：击败狍鸮获得"饕餮纹拓片"，可交给新 NPC「老铸师」铸造**饕餮纹护符**（饰品：佩戴后攻击+3 但受治疗-20%，呼应"贪"的代价），同时图鉴解锁隐藏页"四凶篇"。实现思路：`SaveData` 增加 `items: string[]`，图鉴 `dex` 之外加 `secrets: string[]`；护符做成队伍 buff 常量表。这为后续"四凶"Boss 线（穷奇已有、饕餮、梼杌、浑敦/帝江）埋下收集钩子。

### 今日开发建议

**优先做天狗（tiangou）**：它是三只里"性价比"最高的——① 地图上可直接插进现有"招摇之山 → 天山"传送链，零新区域也能落地（阴山作为中间站）；② "御凶"机制是当前战斗系统（只有 buffDef）最容易扩展成"免疫/减伤"新机制的最小切口；③ 剧情上有"御凶 vs 食月"的现成冲突，能撑起一个支线。**其次是狍鸮**（精英战 + 饕餮纹彩蛋，为"四凶"长线埋伏笔），**孟极**可作北荒野怪池填充，等北荒地图立项时一并做。
