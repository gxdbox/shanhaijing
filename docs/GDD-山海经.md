## 一、定位（制作人拍板）

| 项 | 决策 | 说明 |
|----|------|------|
| 游戏时长 | **中度 8-10 小时** | 重装机兵初见体验 |

## 二、核心玩法（拍板）

| 项 | 决策 | 说明 |
|----|------|------|
| 战斗视角 | **回合制第一人称**（DQ 式） | 沿用现有系统 |
| 异兽数量 | **60-80 只** | 图鉴党满足线，约 1 个月日报攒文案 |
| 养成深度 | **培养**：喂食/羁绊/进化 | 进化 = 收集→培养关键爽点 |
| 队伍配置 | **主角 + 3 只编队** | 才有配队乐趣与抓取决策 |
| 战斗策略 | **属性克制 + 异常状态** | 毒/麻痹/混乱，比纯克制深、比阵型浅 |

## 三、内容结构（拍板）

| 项 | 决策 |
|----|------|
| 区域 | **5 大区域**（南山经→西山经→北山经→东山经→中山经） |
| 剧情 | **中等**：每区域有故事 + 主线贯穿 + 几个支线 |
| 支线 | **每区域 3-5 个**（异兽故事向） |
